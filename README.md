# EngageHub - Community Engagement Platform

**EngageHub** is a community-focused web platform designed to strengthen connections within a society. It allows members to view details about the community, book shared spaces like rooms and halls, and engage in meaningful discussions regarding the community’s development, events, and more.

---

## 🌟 Key Features

### 👤 User Side:
- View complete details about the community.
- Explore available rooms and halls.
- Book rooms or halls for events and functions.
- View and manage their booking history.
- Participate in discussion forums on:
  - Community development
  - Ongoing or upcoming events
  - Emergency situations or announcements
  - General Q&A among members

### 🔒 Admin Side:
- Manage admin users and roles.
- Add / Update / Delete:
  - Community content (info, announcements)
  - Room types and availability
  - Hall details
  - Bookings
- Moderate and manage user discussions.

---

## 🛠️ Tech Stack
- **Backend**: PHP
- **Frontend**: HTML, CSS, JavaScript
- **Database**: MySQL
- **Server**: Apache (XAMPP or similar)
